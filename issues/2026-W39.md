# Agents trained in executable, verifiable environments built from real code and apps

**Rising in ML research, 2026-W39** · papers first posted Sep 7, 2026 to Sep 20, 2026 · [Read on Scholar Feed](https://www.scholarfeed.org/rising/2026-w39)

This week, several teams build agent training environments out of existing software and check the results against execution. ScienceIDE turns scientific repositories into environments, RecreationWorld uses running apps as test oracles, and CodeMidas builds coding tasks from source code. Separately, DeepSeek-V4.1-Flash focuses on making long-horizon agent workloads cheaper to serve by shrinking the KV cache.

## The 10 papers

### 1. [DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression](https://www.scholarfeed.org/paper/2609.19969)

DeepSeek-AI, Anyi Xu et al. · Computation & Language · Impact 49 · [arXiv](https://arxiv.org/abs/2609.19969)

A multimodal MoE model for long-horizon agents that activates 16B parameters per token at decode and 8B at prefill. The authors report a global KV cache footprint of 890 bytes per token, roughly 1/4 that of DeepSeek-V4-Flash, alongside better performance than that baseline.

### 2. [Atria Dawn: The Dawn of Agentic Superintelligence](https://www.scholarfeed.org/paper/2609.15818)

Honglin Guo, Tao Gui et al. · Artificial Intelligence · Impact 21 · 553 GitHub stars · [arXiv](https://arxiv.org/abs/2609.15818) · [Code](https://github.com/atria-asi/Atria-Dawn-Preview)

An agentic language model for research and engineering work, trained on tool interactions tied to executable environments and externally verified outcomes. The authors report the highest score on five of 16 benchmarks and analyze 769 task records from 56 participants on how humans and agents split the work.

### 3. [ScienceIDE: Turning World's Scientific Codebase into Agent Learnable Environments](https://www.scholarfeed.org/paper/2609.19134)

Hejia Geng, Zesen Huang et al. · Computation & Language · Impact 38 · 87 GitHub stars · [arXiv](https://arxiv.org/abs/2609.19134) · [Code](https://github.com/aitofound/ScienceIDE)

Infrastructure in which agents convert scientific code repositories into executable environments for task generation, execution and verification. The authors train 72B, 9B and 4B models on verified trajectories and report gains in held-out scientific-code repair and transfer to general code and reasoning benchmarks.

### 4. [RecreationWorld: Scalable and Verifiable Environments for Hybrid Computer-Use Agents](https://www.scholarfeed.org/paper/2609.22000)

Shuai Bai, Jiayong Deng et al. · Computation & Language · Impact 37 · 84 GitHub stars · [arXiv](https://arxiv.org/abs/2609.22000) · [Code](https://github.com/QwenLM/RecreationWorld)

A five-platform framework in which agents must recreate a running reference application, with the reference acting as an oracle for hidden tests. On the accompanying 250-task benchmark, the authors report the top model at 58.1% overall but passing all programmatic tests on only 2.8% of tasks.

### 5. [LimiX-2: A Contextual Mechanism Network Towards General Structured-Data Intelligence](https://www.scholarfeed.org/paper/2609.17488)

Xingxuan Zhang, Gang Ren et al. · Artificial Intelligence · Impact 30 · 4,298 GitHub stars · [arXiv](https://arxiv.org/abs/2609.17488) · [Code](https://github.com/limix-ldm/LimiX/)

A tabular foundation model pretrained on synthetic causal-model data to learn the joint distribution of features and targets given context, rather than predicting targets alone. The authors report it outperforms dataset-specific and tabular foundation models on TabArena, TALENT and BCCO, and recovers causal skeletons.

### 6. [Zing-0.5: Toward Playable Worlds with Real-Time Joint Action and Text Control](https://www.scholarfeed.org/paper/2609.17909)

Mingyang Chen, Shengdong Chen et al. · Computer Vision · Impact 30 · 163 GitHub stars · [arXiv](https://arxiv.org/abs/2609.17909) · [Code](https://github.com/seedleap/zing-world-model)

A 5B autoregressive world model that users steer with keyboard input and text instructions at the same time, running at 832 x 480 and 24 FPS. The authors report an overall score of 81.0 across 158 WBench Navigation cases and release weights and serving code.

### 7. [COBRA-Skills: Contextual Bandit-Guided Evolution for Agent Skill Optimization](https://www.scholarfeed.org/paper/2609.11682)

Pingchen Lu, Xiangyi Wang et al. · Artificial Intelligence · Impact 15 · 14 GitHub stars · [arXiv](https://arxiv.org/abs/2609.11682) · [Code](https://github.com/Jerry-LuP/COBRA-Skills)

A framework that treats agent skill optimization as budgeted search, using a contextual bandit to decide which candidate skills to evaluate. The authors report the best average performance across six benchmarks at 55-58% lower cost than SkillOpt, using 50 optimization examples per benchmark.

### 8. [Vidu S2: Real-Time Interactive, Editable, and Spatial Video Generation](https://www.scholarfeed.org/paper/2609.11638)

Jintao Zhang, Kai Jiang et al. · Computer Vision · Impact 14 · [arXiv](https://arxiv.org/abs/2609.11638)

A real-time video system with two parts: an interactive digital-character model generating 720p video with references that can be updated mid-stream, and a model that edits live video streams by changing style, clothing, characters or backgrounds. The authors report it outperforms all baselines.

### 9. [Miles v0.1: Production-Level Post-Training](https://www.scholarfeed.org/paper/2609.08368)

RadixArk, Tom Chen et al. · Machine Learning · Impact 14 · 3,001 GitHub stars · [arXiv](https://arxiv.org/abs/2609.08368) · [Code](https://github.com/radixark/miles)

An open-source post-training RL system with SGLang rollouts, two trainer backends and support for LoRA RL, on-policy distillation and diffusion models. In a case study, the authors report asynchronous agentic RL on a 744B-A40B model on 64 GB300 GPUs with a median step time of 263 seconds.

### 10. [CausalWM: Causal Chain-of-Thought Reasoning for Embodied World Model](https://www.scholarfeed.org/paper/2609.23184)

Ziming Xu, Shuang Liang et al. · Computer Vision · Impact 28 · 43 GitHub stars · [arXiv](https://arxiv.org/abs/2609.23184) · [Code](https://github.com/AetherLabsAI/CausalWM)

A 16B embodied world model that writes out a causal chain of reasoning before predicting future video, trained on 31K hours of embodied data in three stages. The authors report leading results on language- and action-conditioned benchmarks, including Top-1 on the TriWorldBench leaderboard.

## Also moving

- [NemotronLabs VoiceChat: An Open Full-duplex Speech-to-Speech Model with Tool Calling Capabilities](https://www.scholarfeed.org/paper/2609.21967): An open full-duplex speech-to-speech model that listens, transcribes, calls tools and speaks within one streaming architecture.
- [ModularRSI: Modular and Generalizable Recursive Harness Self-Improvement](https://www.scholarfeed.org/paper/2609.14857): Evolves coding-agent harnesses module by module on tasks kept separate from evaluation benchmarks, so the gains carry over to unseen tasks.
- [RPMem: Learning Long-Term Recurrent Parametric Memory Across Sessions for LLM Agents](https://www.scholarfeed.org/paper/2609.23466): Compiles each session into latent memory, merges it across sessions with a gate, and maps it to LoRA weights for any backbone.
- [ExecCritic: Learn to Test, Test to Improve for Coding Agents](https://www.scholarfeed.org/paper/2609.09133): Trains separate test-writing and repair agents with RL and reports 72.6% on SWE-bench Verified when the two are combined.
- [CodeMidas: Scaling Agentic Coding RL Environments from Code Itself](https://www.scholarfeed.org/paper/2609.22068): An agentic pipeline that turns implemented functionality in open-source codebases into 5,545 verifiable RL tasks for coding agents.
