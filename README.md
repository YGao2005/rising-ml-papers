## How papers are chosen

Papers first posted to core ML/AI arXiv categories in the previous two weeks, ranked by
Scholar Feed's forecast impact score, at most three per category, and each paper featured
only once. The notes are generated from each paper's abstract and summary and are rejected
automatically if they cite any number the source does not contain.
[Methodology](https://www.scholarfeed.org/methodology).
